# Complete-checkpoint evidence and reference import boundaries

The new `peri_actual_checkpoint_support.py` does not dispatch a solver or
perform a material review. It keeps three independent obligations separate:

1. A full original 95-digit review authenticates the NEW continuous native raw,
   all trial point tangents/R/J, true mass, histories, geometry and8 negatives.
2. The binary oracle reconstructs all138 fields of every physical accepted
   record from its native JSON bit patterns, using the independently qualified
   initial body/contract. It reconstructs complete140-field candidates at
   press8,hold20,release32,final40. Every archive byte and physical prefix byte
   must equal the explicit selected native generation, not merely final force.
3. Each planned seed/resume/rollback native emits its full original Newton
   records. A byte-identical ENTIRE step line can import the authenticated
   continuous mathematical evidence. Changed or dropped trial packets cannot
   be hidden behind equal accepted endpoints. Distinct process identity and
   explicit resume headers are metadata, never fabricated t0 observations.

If any new trial packet differs, it requires the prospectively frozen new
context reference assessment. Accepted state and physical output byte equality
remain mandatory. A differing Newton path is never justification for relaxing
state/output comparison or silently treating endpoint-only agreement as proof.
No old already-qualified raw reference is rerun just to generate new receipts.

The9 new parser unit checks cover entire trial packet identity, tangent change
with equal endpoints, removed trial data, planned seed prefixes, header change,
structural clock/count/commit/extra-record rejection, truncated records, and
selected-generation/full-prefix integrity. They use synthetic trace packets and
the immutable zero-advance initial fixture as NEW format inputs; no native
solver, constitutive calculation or old physical review is called. These tests
do not qualify an actual physical restart or S3 as a whole.

Positive noadvance requires the actual owned restore-and-resave path. Read-only
validation alone is insufficient. Metadata must report zero solves/zero new
steps, installed-and-resaved ownership and the unchanged explicit logical
generation; full archive/physical bytes and preservation of prior files are
checked separately. The new parser refuses a read-only receipt, hidden solve,
missing installed state or generation retagging. The native preflight uses
logicalG7 at physicalstep0; actual nonzero press/hold/release tests remain due.

This is a static inventory, not a substitute for actual new native split/
rollback/noadvance and correct-hash semantic rejection experiments.

The canonical physical stream includes every accepted material state and both
plate interval reactions/impulses/work plus each separate physical/algorithmic

its own failure cursor and is authenticated by complete raw receipts before
dependent experiments. A sealed checkpoint is published after its corresponding
full step JSON has flushed/fsynced. PID, process wall time and resume markers
are not physical bytes. No instantaneous-terminal-force claim is made.
